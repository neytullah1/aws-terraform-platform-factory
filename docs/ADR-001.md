# ADR-001: Platform factory with controlled flexibility

**Decision:** Reusable versioned modules encode non-negotiable security invariants; compositions bundle common nested relationships; consumer roots select validated business parameters. Scalr owns remote plan/apply and state. GitHub validates PRs.

**Why:** Product teams can tune operational inputs without copying templates or editing security controls. Security-owned plan policies detect bypass via raw resources.

**Trade-offs:** Registry and policy governance add operational overhead; composition modules may become too opinionated. Use narrow module interfaces, deprecation windows, semver and versioned ADRs.

**Exception model:** request, business justification, scope, owner, expiration, compensating control, security approval, audit trail. No consumer-controlled `disable_security = true` switch.
